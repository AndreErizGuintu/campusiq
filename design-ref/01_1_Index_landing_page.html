Features

What CampusIQ does

Records in one place
Grades, attendance and library records together. Built to work with whatever dataset the school uses.
Ask in plain language
Staff type questions like "who's absent today" and get answers and summaries instead of scrolling tables.
Automatic email alerts
Students and parents are emailed the moment a grade is posted, an absence is logged or a book is overdue.
PDF reports on demand
Any record becomes a downloadable slip, summary or receipt, generated on the spot.
APIs used

3 API's

Gemini API
API 1
Google's AI model. Powers the AI Assistant page: plain-language questions and record summaries.
ai.google.dev
EmailJS API
API 2
Sends emails straight from the browser, no mail server. Powers the Email Alerts page.
emailjs.com
PDFShift API
API 3
Converts a record page into a PDF file. Powers the PDF Reports page.
pdfshift.io
